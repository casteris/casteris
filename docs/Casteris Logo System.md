# 1. Propósito

El Casteris Logo System establece la referencia oficial para el uso del logotipo de la marca.

Su objetivo es garantizar que todas las aplicaciones de la identidad visual utilicen exactamente el mismo sistema de construcción, proporciones y variantes.

Este documento complementa al Casteris Brand Design Guide.

---

# 2. Componentes oficiales

El sistema de identidad está compuesto por tres elementos.

## Foundation Mark

Versión oficial:

B5

Características:

- geometría simple
- apertura ópticamente equilibrada
- esquinas suavizadas
- estructura abierta
- construcción modular

## Wordmark

Versión oficial:

Dirección C

Características:

- basado en Inter SemiBold
- refinamiento óptico personalizado
- ajustes específicos en "a", "r" y "s"
- tracking optimizado
- personalidad propia

## Logo principal

Configuración oficial:

Foundation Mark + Wordmark horizontal.

Esta constituye la representación principal de Casteris.

---

# 3. Variantes oficiales

El sistema contempla únicamente cuatro configuraciones.

## Principal

Imagotipo horizontal.

Uso por defecto.

## Vertical

Uso en espacios verticales.

## Solo símbolo

Uso en favicon, avatar y aplicaciones reducidas.

## Solo wordmark

Uso excepcional cuando el símbolo no sea necesario.

No deberán crearse nuevas configuraciones sin una actualización formal del Logo System.

---

# 4. Versiones cromáticas

Las únicas versiones oficiales son:

- Principal
- Negativa
- Monocromática

No deberán utilizarse colores alternativos.

---

# 5. Área de protección

El área mínima de protección corresponde a una unidad X alrededor del conjunto completo.

Ningún elemento gráfico podrá invadir esta zona.

---

# 6. Tamaño mínimo

Digital

16 px

Impresión

8 mm

Por debajo de estos tamaños deberá utilizarse únicamente el Foundation Mark.

---

# 7. Usos incorrectos

No está permitido:

- deformar el logotipo;
- alterar proporciones;
- modificar el espaciado;
- cambiar la tipografía;
- reemplazar el Foundation Mark;
- utilizar colores distintos de la paleta oficial;
- aplicar efectos visuales.

---

# 8. Relación con otros documentos

Este documento debe utilizarse conjuntamente con:

- Casteris Brand Blueprint
- Casteris Brand Design Guide

---

# 9. Estado

La versión v1.0 oficializa el sistema de logotipo de Casteris.

A partir de esta versión, todas las aplicaciones de la identidad visual deberán utilizar exclusivamente las variantes aquí definidas.

Las futuras modificaciones deberán realizarse mediante control de versiones.
