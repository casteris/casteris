# 1. Propósito del documento

El Casteris Brand Design Guide establece los principios que regirán la identidad
visual de la marca. Su objetivo es asegurar que todas las decisiones
relacionadas con diseño, experiencia visual y comunicación gráfica
mantengan coherencia con el Casteris Brand Blueprint.

------------------------------------------------------------------------

# 2. Relación con el Casteris Brand Blueprint

Este documento traduce visualmente la estrategia definida en el Casteris
Brand Blueprint. No redefine el propósito, posicionamiento ni la
audiencia; establece cómo esos elementos se expresan mediante el diseño.

------------------------------------------------------------------------

# 3. Filosofía de diseño

## 3.1 Innovación con propósito

La innovación deberá percibirse como consecuencia del pensamiento y la
capacidad para construir soluciones.

## 3.2 Cercanía profesional

La identidad deberá sentirse accesible sin perder credibilidad.

## 3.3 Claridad antes que complejidad

El diseño deberá reducir la carga cognitiva mediante jerarquías claras y
estructuras limpias.

## 3.4 Creatividad estructurada

La creatividad deberá expresar significado y nunca convertirse en ruido
visual.

## 3.5 Construcción continua

La identidad deberá comunicar evolución, aprendizaje y mejora continua.

------------------------------------------------------------------------

# 4. Personalidad visual

La identidad buscará ser:

-   Profesional sin ser distante.
-   Innovadora sin seguir modas.
-   Creativa sin perder claridad.
-   Cercana sin perder autoridad.
-   Tecnológica sin depender de clichés.
-   Atemporal con capacidad de evolución.

------------------------------------------------------------------------

# 5. Principios de diseño

1.  Claridad sobre decoración.
2.  Consistencia antes que originalidad.
3.  Simplicidad con profundidad.
4.  La información guía el diseño.
5.  Modularidad.
6.  Accesibilidad por defecto.
7.  Evolución incremental.
8.  Evidencia sobre apariencia.

------------------------------------------------------------------------

# 6. Atributos visuales de la marca

Los elementos gráficos deberán transmitir:

-   Claridad
-   Confianza
-   Innovación
-   Cercanía
-   Creatividad
-   Estructura
-   Evolución

Estos atributos servirán como criterios para evaluar cualquier decisión
de diseño.

------------------------------------------------------------------------

# 7. Sistema cromático

El sistema cromático se organizará en:

-   Color primario.
-   Color secundario.
-   Color de acento.
-   Paleta de neutros.
-   Colores funcionales.

El color reforzará la comprensión y nunca sustituirá una buena
estructura visual.

------------------------------------------------------------------------

# 8. Evaluación estratégica del color principal

Tras evaluar profesionalismo, innovación, cercanía, creatividad,
diferenciación y coherencia con el Blueprint, se adopta como dirección
estratégica una familia cromática basada en morados, complementada por
turquesas, una familia cálida de acento y una base sólida de neutros.

------------------------------------------------------------------------

# 9. Arquitecturas cromáticas candidatas

Durante el proceso de diseño se evaluaron tres arquitecturas:

-   Strategic Purple.
-   Executive Blue.
-   Intelligent Graphite.

Se seleccionó Strategic Purple por representar con mayor fidelidad la
combinación de conocimiento, creatividad, innovación y liderazgo
definida en la estrategia de marca.

# 11. Sistema tipográfico

## Objetivo

La tipografía deberá reforzar la claridad, el profesionalismo y la
facilidad de lectura.

## Principios

-   Priorizar legibilidad.
-   Escalabilidad en web y móvil.
-   Excelente soporte Unicode.
-   Apariencia moderna y atemporal.

## Recomendación inicial

### Tipografía principal

**Inter**

Uso: - interfaz - sitio web - documentación - aplicaciones -
presentaciones

### Tipografía monoespaciada

**JetBrains Mono**

Uso: - código - comandos - ejemplos técnicos

------------------------------------------------------------------------

# 12. Logotipo

El logotipo deberá representar una marca de conocimiento y construcción
tecnológica.

No utilizará símbolos genéricos como circuitos, chips, engranajes o
robots.

Su construcción deberá ser simple, memorable y escalable.

------------------------------------------------------------------------

# 13. Isotipo

El isotipo deberá funcionar de manera independiente del nombre y ser
reconocible en tamaños pequeños.

Su diseño deberá transmitir estructura, aprendizaje y construcción.

------------------------------------------------------------------------

# 14. Imagotipo

La combinación del logotipo y el isotipo constituirá la versión
principal para comunicaciones institucionales.

Deberá existir una versión horizontal y otra vertical.

------------------------------------------------------------------------

# 15. Área de protección y tamaños mínimos

Se definirá un área de seguridad alrededor del logotipo para garantizar
su correcta visibilidad.

También se establecerán tamaños mínimos para uso digital e impreso.

------------------------------------------------------------------------

# 16. Sistema de iconografía

Los iconos deberán compartir un mismo lenguaje visual.

Principios:

-   geometría simple
-   grosor consistente
-   esquinas suavizadas
-   fácil reconocimiento
-   compatibilidad con interfaces y documentación

Se priorizarán bibliotecas de iconografía de estilo lineal para mantener
claridad y uniformidad.

------------------------------------------------------------------------

# 17. Sistema de ilustraciones

Las ilustraciones deberán apoyar la comprensión de conceptos y no
sustituir el contenido.

Características:

-   composición limpia
-   formas geométricas
-   elementos tecnológicos abstractos
-   ausencia de personajes caricaturescos
-   énfasis en ideas y procesos

------------------------------------------------------------------------

# 18. Fotografía

La fotografía deberá transmitir autenticidad y profesionalismo.

Preferencias:

-   entornos reales de trabajo
-   colaboración entre personas
-   dispositivos y pizarras
-   iluminación natural
-   evitar imágenes excesivamente artificiales o de stock evidentes

------------------------------------------------------------------------

# 19. Diagramas técnicos

Los diagramas forman parte de la identidad de la marca.

Deberán seguir principios de:

-   simplicidad
-   consistencia
-   nomenclatura uniforme
-   jerarquía visual clara
-   uso moderado del color

------------------------------------------------------------------------

# 20. Componentes gráficos

Los recursos gráficos deberán construirse como un sistema reutilizable.

Incluyen:

-   tarjetas
-   etiquetas
-   bloques destacados
-   tablas
-   citas
-   timelines
-   diagramas
-   callouts

Todos deberán compartir reglas comunes de espaciado, tipografía y color.

------------------------------------------------------------------------

# 21. Aplicaciones de marca

La identidad deberá implementarse de manera consistente en:

-   sitio web
-   portafolio
-   GitHub
-   LinkedIn
-   presentaciones
-   documentación técnica
-   artículos
-   miniaturas
-   firmas de correo
-   tarjetas digitales
-   propuestas comerciales

Cada canal conservará la misma estructura visual, tipografía, jerarquías
y sistema cromático.

------------------------------------------------------------------------

# 22. Consistencia visual

Toda pieza deberá respetar:

-   sistema cromático oficial
-   tipografía oficial
-   componentes reutilizables
-   espaciado uniforme
-   iconografía consistente
-   estilo fotográfico
-   diagramas normalizados

La consistencia tendrá prioridad sobre la experimentación.

------------------------------------------------------------------------

# 23. Accesibilidad

Toda interfaz o material gráfico deberá:

-   cumplir criterios adecuados de contraste
-   mantener tamaños legibles
-   evitar depender únicamente del color
-   funcionar correctamente en escritorio, tableta y móvil
-   favorecer una lectura cómoda durante largos periodos

------------------------------------------------------------------------

# 24. Restricciones de uso

No se permitirá:

-   alterar arbitrariamente la paleta oficial
-   deformar el logotipo
-   combinar tipografías no autorizadas
-   utilizar iconografía de estilos incompatibles
-   introducir efectos visuales que contradigan la filosofía de diseño
-   romper la consistencia entre productos y canales

------------------------------------------------------------------------

# 25. Evolución de la identidad

La identidad visual evolucionará mediante mejoras incrementales.

Toda modificación deberá:

-   mantener compatibilidad con versiones anteriores cuando sea posible
-   responder a una necesidad justificada
-   documentarse mediante control de versiones
-   respetar el Casteris Brand Blueprint

------------------------------------------------------------------------

# 26. Estado del documento

El Casteris Brand Design Guide v0.5 representa una guía funcional prácticamente
completa.

Antes de aprobar la versión v1.0 deberá realizarse una revisión integral
para:

-   eliminar redundancias
-   unificar estilo editorial
-   validar reglas de aplicación
-   incorporar ejemplos visuales y mockups en una edición posterior

# Política de mantenimiento

Este documento constituye la referencia oficial de identidad visual de Casteris y
deberá evolucionar únicamente mediante versiones controladas.
